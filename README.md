# Project Selector

An Arabic, mobile-friendly page where a guardian picks one Claude Code project type for their hero or heroine, writes the hero's name and any special notes, and sends it.

- `index.html` — the public page (no login). Submissions are saved to the `project_requests` table in Supabase (First Project).
- `admin.html` — private page for Ahmad to see incoming projects, mark them done or delete them (admin login).
